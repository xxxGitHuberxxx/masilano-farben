# Masilano Farben – Malen nach Zahlen (PWA-Prototyp)

- `app/`: source incl. `window.__dbg` test hook. `dist/`: deployable build (hook removed). Build: `/workspace/venv/bin/python tools/build.py` (copies app→dist, writes `sw.js` with a content-hash cache version into both).
- Preprocessing: `tools/prep.py` (venv `/workspace/venv`); v1 settings kept in `tools/prep_v1.py`. The 4 original puzzles (starry, wave, pearl, lilies) were NOT reprocessed so saved progress (`localStorage masilano.color.v1.<id>`, checked against region count) stays valid. Never change an existing id or its json/map.
- PWA: `manifest.webmanifest`, `icons/`, `sw.js` (shell refreshed per version, painting data reused from the old cache because it is treated as immutable; navigation network-first, everything else cache-first, works offline). All paths relative, so it runs under `/masilano-farben/`.
- Tests: `tools/test.py` (main, v4: Franz-Marc story + Van-Gogh regressions + screenshots `screens/v4-*`), `tools/test2.py` (plays all 20 gallery works), `tools/test_v1.py` (old v1). All serve `app/` under /masilano-farben/ on :8766.

## Geschichten (Story-Modus, v3/v4)

- `app/story.js`: `window.STORIES` (chapters: `pid`, place, when, title, text, fact; intro/epilogue) and `window.STORY_WORKS` (story-only works, not shown in the 20-work gallery). Home screen shows one banner per story; a story with `fresh:true` is marked «Neu».
- Chapter *n* unlocks when the work of chapter *n-1* is finished. Progress per work uses the same key `masilano.color.v1.<id>` as the gallery, so Sternennacht, Sonnenblumen and Caféterrasse count in both places. `masilano.story.v1.<storyId>` only stores which chapter texts were opened (`{seen:[...]}`). Van Gogh uses `masilano.story.v1.vangogh`, Franz Marc `masilano.story.v1.marc`.
- Kapitel Vincent van Gogh: potato (1885), felthat (1887), sunflowers (1888), cafe (1888), bedroom (1888), starry (1889), almond (1890), crows (1890). New works downloaded with `tools/dl_vg.py`, prepared with `tools/prep.py potato felthat bedroom almond crows`.
- Kapitel Franz Marc (v4): grazing (1910), bluehorse (1911), largeblue (1911), tiger (1912), foxes (1913), fate (1913), deer (1914), forms (1914). «Der Turm der blauen Pferde» was skipped (lost since 1945; only modest reproductions on Commons). Downloaded with `tools/dl_marc.py`, prepared with `tools/prep.py grazing bluehorse largeblue tiger foxes fate deer forms`.
